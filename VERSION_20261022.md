# Version 2026-10-22: evidence-alignment update

No previously reported primary model metric or historical prediction file is changed by this documentation revision. This branch adds aggregate sensitivity outputs and clarifies provenance and execution limits.

## Changes in this revision

1. Correct the public documentation: the historical preprocessing script, complete source-label frequency table and contemporaneous execution log were not recovered. An internal \`dataset_stats.json\` reports 278 raw labels and 42 eligible/selected labels; the 278 count and uniqueness of the threshold-based selection cannot be independently recomputed.
2. Change the generic paired-bootstrap index generator in \`code/pairwise_stats.py\` to the archived \`random.choices(..., k=n)\` with-replacement generator, because \`randrange\` consumes the RNG stream differently and does not reproduce the archived interval endpoints exactly.
3. Add Qwen3 Stage-2 scope documentation, Seed-7 inference-provenance documentation, and aggregate data-quality counts with explicit private-input boundaries.
4. Add \`results/dedup_sensitivity_seed42.csv\` and its portable computation script. The sensitivity table is derived from frozen predictions, retains the minimum numeric ID suffix per duplicate group, and uses the audited NFKC/digit-sentinel normalization for the normalized-text stress test; it does not replace the primary analysis.
5. Preserve the InternLM3 locked design ranges in the protocol JSON and add a separate execution clarification that the historical script did not execute the planned Stage-2 unfreezing routine.
6. Keep the existing public evidence map and aggregate verification script; no private clinical records, case-level predictions, model weights, stdout logs, or near-duplicate pair-level text are added.

This is a proposed public-repository revision on a review branch. It is not part of \`main\` unless and until the pull request is merged.
