# Data directory

No clinical records are included in this public repository.

The study's derived records use fields conceptually similar to:

```json
{
  "id": "derived_record_id",
  "input_text": "<clinical presentation text>",
  "syndrome_raw": "<original syndrome annotation>",
  "syndrome_canonical": "<one of the 42 fixed labels>"
}
```

`schema_example.json` is synthetic and contains no patient data.
