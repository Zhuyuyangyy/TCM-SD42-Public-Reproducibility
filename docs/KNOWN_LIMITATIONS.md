# Known limitations

1. **Derived task, not the official 148-class benchmark.** TCM-SD42 uses a historical 42-class task taxonomy based on original `syndrome` annotations; it is not identical to the official normalized 148-class TCM-SD label space.
2. **Historical task construction used test-label support.** A surviving preprocessing log shows that categories were eligible when support was at least 100/10/10 in the original train/development/test splits, respectively; exactly 42 source syndrome labels met all three thresholds. This procedure predates the present four-model comparison and did not use model predictions, but it means historical task definition was informed by test-label frequency.
3. **Original preprocessing source file unavailable.** The operational support thresholds are recoverable from the surviving 2026-05-07 preprocessing log, but the original source file that implemented the historical selection is not included in the current public package.
4. **Training-development redundancy.** Fifty-four development instances were involved in train-development pairs with similarity >=0.95, including 18 exact duplicates. In a ZY-BERT sensitivity analysis, removing overlap-affected development instances reduced development macro-F1 from 0.8056 to 0.7742. The clean held-out test set is therefore treated as the principal evidence.
5. **Patient-level independence cannot be established.** The frozen derived files do not contain a reliable patient identifier suitable for proving patient-disjoint splits. The study establishes text-level decontamination, not guaranteed patient-level independence; case-level bootstrap and McNemar analyses cannot account for possible within-patient correlation.
6. **Class imbalance.** The primary 4,218-case test set is strongly imbalanced; Macro-F1 and Balanced Accuracy should be interpreted alongside overall Accuracy.
7. **Checkpoint-selection mismatch for historical Qwen3.** The frozen Qwen3 checkpoint was selected by development loss, whereas later comparative models use development Macro-F1. This is disclosed rather than retroactively changed.
8. **No reliable public per-class F1 table from the v20 aggregate file.** An internal per-class CSV was found to be column-inconsistent and is intentionally excluded from this public release. Confusion matrices and aggregate metrics are retained.
9. **System-level rather than factorial causal comparison.** The evaluated systems differ in architecture, pretraining corpora, tokenization, model size, and adaptation recipes; the study does not isolate a single causal effect of domain pretraining or model scale.
10. **No formal efficiency benchmark.** The study does not report controlled latency, FLOPs, energy use, or cost comparisons, so no quantitative efficiency claim is made.
11. **No claim of clinical deployment.** The task is a retrospective benchmark classification study and does not establish diagnostic safety, prospective clinical effectiveness, or deployment readiness.
